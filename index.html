Consent banner dev demo

The banner renders below. Narrow the viewport under 640px (or use the browser device toolbar) to check the mobile button layout. All action buttons should share the same height and padding.

The /api/geo endpoint is stubbed by the dev server and resolves the regime from query params (the element forwards country, region, and gpc), just like the real endpoint in non-production. With no params it falls back to the strict opt_in regime.

  • no params: opt_in (GDPR-style)
  • ?country=US&region=CA: us_opt_out (Do not sell)
  • ?country=US&region=NY: us_basic
  • ?country=US&region=CA&gpc=1: us_opt_out with GPC

To change regime, click Clear stored consent & reload first. A prior decision is persisted in localStorage and a consent cookie, either of which suppresses the banner on reload.
